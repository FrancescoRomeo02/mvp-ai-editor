# Official LaTeX style packages

Downloaded packages and instructions used by the editor's restricted journal-profile selector:

- `acm/`: ACM `acmart` package from CTAN, referenced by ACM author documentation: <https://www.ctan.org/pkg/acmart>
- `nature/`: Nature's official author instructions are configuration-driven and require standard `article.cls`; they do not provide a Nature-specific class: <https://www.nature.com/nature/for-authors/final-submission>

The `springer-nature/` and `elsevier/` packages remain available as downloaded assets, but are not offered by the ACM/Nature selector.

Journal-specific author guidelines still take precedence over these publisher templates.
